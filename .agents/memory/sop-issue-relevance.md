---
name: SOP issue relevance
description: How to prevent a supported proposition for one issue from answering a neighboring issue in a compound SOP question.
---

The final relevance decision must require a claim to answer both the validated source-derived policy issue and the requested discrete sub-question. Apply that same focus check to fallback policy-issue clauses; overlap ranking alone can revive a rejected neighboring issue.

**Why:** A compound question about a supported guaranty issue and an unsupported market-rate issue intermittently admitted the guaranty conclusion for both planner outputs when the audit saw only the source-derived issue. A rejected seller-note issue also fell through to overlap-only fallback and selected a nearby working-capital clause because it mentioned seller financing.

**How to apply:** Preserve the retrieval-seed sub-question on every candidate and include it in citation/relevance auditing alongside the source clauses. Require model-derived and fallback policy-issue clauses to pass the same focus gate before using them as the canonical issue. Reject adjacent-issue claims even when their citations are valid.
